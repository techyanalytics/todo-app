📌 Basic Todo App (HTML, CSS, JavaScript)
📝 Project Description

This is a basic Todo App built using HTML, CSS, and JavaScript.
The project is created for learning purposes to understand JavaScript fundamentals.

In this project, I learned:

How JavaScript objects work

How data is stored and managed

What LocalStorage is and how it works

How to add, delete, and manage items dynamically using JavaScript

This is just the beginning of my web development journey.
I will continue learning more concepts and aim to make meaningful contributions to the web.

🚀 Features

Add todo items

Delete todo items

Automatically saves data using LocalStorage

Data remains even after page refresh

Simple and clean UI

🛠️ Technologies Used

HTML – Structure

CSS – Styling

JavaScript – Logic & functionality

LocalStorage – Data persistence

🧠 What I Learned

JavaScript objects and arrays

DOM manipulation

Event handling

How data is saved in key–value format

Difference between temporary data and persistent data

Basics of project structuring
